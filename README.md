# Smart Editing - Premiere Pro 智能序列创建工具

## 简介

Smart Editing 是一个专为 Adobe Premiere Pro 设计的 Python 工具，能够自动化音视频匹配和序列创建，大幅提升视频剪辑效率。

### 核心功能

- **智能音视频匹配** - 基于文件名数字自动配对音视频文件
- **多轨道音频布局** - 智能检测视频音频占用，避免轨道冲突
- **一键序列创建** - 使用 Premiere Pro 原生功能保证最佳质量
- **音频轨道控制** - 精确的静音/取消静音功能

### 智能轨道分配

程序会自动分析序列中的音频轨道：
```
A1: [视频音频] ← 自动检测
A2: [外录音频1] ← 从这里开始放置外录音频
A3: [外录音频2]
A4: [外录音频3]
...
```

## 安装和环境要求

### 系统要求
- Windows 10/11
- Python 3.7 或更高版本
- Adobe Premiere Pro (任何支持的版本)

### 依赖库安装
```bash
pip install pymiere
```

## 使用方法

### 1. 准备工作
1. 启动 Adobe Premiere Pro
2. 打开或创建一个项目
3. 确保项目中有需要处理的音视频文件

### 2. 启动程序

#### 方法一：双击启动（推荐）
```
双击 START.bat
```

#### 方法二：命令行启动
```bash
python smart_editing.py
```

#### 方法三：Python启动器
```bash
python 启动程序.py
```

### 3. 操作步骤
1. 程序启动后会自动连接 Premiere Pro
2. 确认连接状态显示正确的项目名称
3. 可选：勾选"静音视频轨道"（使用外录音频时推荐）
4. 点击"一键创建序列"按钮
5. 程序会自动扫描项目文件，匹配音视频，创建序列

## 文件匹配规则

程序使用智能算法匹配音视频文件：

### 数字匹配示例
```
"视频01.mp4" ↔ "音频01.mp3"     # 匹配数字: 01
"scene_05.mov" ↔ "voice_05.wav" # 匹配数字: 05
"clip-10.mp4" ↔ "audio-10.m4a"  # 匹配数字: 10
```

### 支持的文件格式
- **视频**: .mp4, .mov, .avi, .mkv, .m4v, .wmv
- **音频**: .mp3, .wav, .aac, .m4a

## 功能特性

### 智能音频轨道检测
- 自动识别视频音频占用的轨道数量
- 支持单声道和立体声视频音频
- 外录音频从视频音频轨道之后开始放置

### 文件夹分组
- 不同文件夹的音频文件分配到不同轨道
- 保持项目结构的逻辑清晰

### 序列创建
- 使用 Premiere Pro 原生 "从片段新建序列" 功能
- 自动设置最佳画质和音质参数
- 保持原始文件的所有属性

## 故障排除

### 常见问题

#### 1. 程序无法启动
**症状**: 双击START.bat没有反应或报错
**解决方案**:
```bash
# 检查Python是否正确安装
python --version

# 检查pymiere库
python -c "import pymiere; print('pymiere可用')"

# 手动安装pymiere
pip install pymiere
```

#### 2. 连接Premiere Pro失败
**症状**: 显示"连接失败"或"未找到打开的项目"
**解决方案**:
- 确保 Premiere Pro 已启动
- 确保已打开一个项目（不能是空的启动页面）
- 点击程序中的"刷新项目"按钮
- 重启 Premiere Pro 和程序

#### 3. 文件匹配失败
**症状**: 没有找到匹配的音视频文件
**解决方案**:
- 检查文件名是否包含相同的数字
- 确认文件扩展名在支持列表中
- 文件必须已导入到 Premiere Pro 项目中

#### 4. 音频轨道分配错误
**症状**: 外录音频覆盖了视频音频
**解决方案**:
- 程序会自动检测并避免此问题
- 如果仍有问题，请检查序列中的现有内容

### Python环境问题

## 使用技巧

### 最佳实践
1. **文件命名**: 使用统一的数字编号，如 `视频01.mp4` 和 `音频01.mp3`
2. **项目组织**: 将相关的音视频文件放在同一文件夹中
3. **预检查**: 启动程序前确保 Premiere Pro 项目已正确打开
4. **备份**: 在使用自动化工具前建议备份项目文件

### 工作流建议
1. 导入所有音视频文件到 Premiere Pro
2. 按照统一规则重命名文件（如果需要）
3. 启动 Smart Editing 工具
4. 一键创建序列
5. 检查生成的序列，进行必要的微调
