# SRT字幕自动导入工具 - 快速使用指南

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动程序
- **测试版本**: 双击 `START_TEST.bat`
- **完整版本**: 双击 `START_SRT_IMPORTER.bat`

## 📋 使用步骤

### 步骤1: 文件扫描
1. 点击"浏览"选择包含SRT文件的目录
2. 点击"扫描SRT文件"
3. 查看扫描结果

### 步骤2: 文件匹配 ⭐ 已修复
- 程序会自动匹配SRT文件和PR中**已创建的序列**
- 基于文件名中的数字进行智能匹配
- 例如：`01.srt` ↔ `序列01`

### 步骤3: 坐标配置
配置四个关键坐标：
1. **坐标1**: PR中的"导入"按钮
2. **坐标2**: 字幕样式下拉菜单
3. **坐标3**: 具体样式选项
4. **坐标4**: 确定按钮

**操作方法**: 点击"获取坐标" → 移动鼠标到目标位置 → 按F1键

**✨ 新功能**: 坐标配置会**自动保存**，下次打开程序时会自动加载之前的配置！

### 步骤4: 执行导入 ⭐ 已修复
- 程序会使用**剪贴板粘贴路径**，避免中文路径问题
- 按数字顺序自动导入所有匹配的SRT文件
- 每个文件导入到对应的序列中

## ⚠️ 注意事项

### 使用前准备
1. **启动Premiere Pro**并打开项目
2. **确保已创建好序列**（程序匹配的是序列，不是视频文件）
3. **准备好SRT文件**，文件名包含数字编号

### 文件命名规范
```
SRT文件          →  对应序列
01.srt          →  序列01 / Sequence01 / Episode01
字幕02.srt      →  序列02 / Sequence02 / Episode02
subtitle_03.srt →  序列03 / Sequence03 / Episode03
```

### 操作环境
- 确保PR界面完全可见
- 导入过程中不要移动鼠标
- 建议关闭其他不必要的程序

## 🔧 故障排除

### 常见问题
1. **连接PR失败** → 确保PR已启动并打开项目
2. **找不到序列** → 确保PR中已创建对应的序列
3. **路径问题** → 现在使用剪贴板粘贴，应该已解决
4. **坐标不准** → 重新配置坐标，确保PR界面没有缩放

### 依赖问题
```bash
# 如果缺少依赖，手动安装
pip install pymiere pyautogui keyboard pyperclip
```

## 📞 技术支持

如果遇到问题：
1. 查看程序日志输出
2. 确认按照步骤正确操作
3. 检查PR中是否已创建对应序列
4. 验证SRT文件命名是否包含数字
