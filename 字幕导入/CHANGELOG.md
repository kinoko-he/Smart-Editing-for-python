# SRT字幕自动导入工具 - 更新日志

## v1.2 - 2024/09/27

### ✨ 新增功能
- **坐标自动保存** - 配置好的坐标会自动保存到 `coordinates_config.json` 文件
- **坐标自动加载** - 程序启动时会自动加载之前保存的坐标配置
- **坐标状态显示** - 实时显示坐标配置状态和保存状态，带颜色标识
- **坐标清除功能** - 提供一键清除所有坐标配置的功能

### 🔧 技术改进
- 使用JSON格式保存坐标配置，确保数据完整性
- 优化了坐标配置界面的用户体验
- 修复了程序启动时的初始化顺序问题

## v1.1 - 2024/09/27

### 🔧 修复问题
- **修复步骤二文件匹配** - 改为匹配SRT文件和已创建的序列，不再匹配视频音频文件
- **移除素材箱功能** - 完全移除自动创建素材箱的功能，简化操作流程
- **修复路径粘贴问题** - 使用剪贴板粘贴路径，避免特殊字符和中文路径问题

### ✨ 功能改进
- 改进序列检测逻辑，直接从 `project.sequences` 获取已创建的序列
- 使用 `pyperclip` 库进行剪贴板操作，提高路径处理的可靠性
- 简化步骤4界面，专注于核心导入功能

### 📦 依赖更新
- 新增依赖：`pyperclip>=1.8.2`

### 🎯 核心功能
1. **步骤1**: 扫描SRT文件目录
2. **步骤2**: 智能匹配SRT文件与PR中已创建的序列
3. **步骤3**: 配置四个关键操作坐标
4. **步骤4**: 自动化批量导入字幕到对应序列
