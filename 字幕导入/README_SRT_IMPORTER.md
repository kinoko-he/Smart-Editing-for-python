# SRT字幕自动导入工具

## 简介

SRT字幕自动导入工具是一个专为 Adobe Premiere Pro 设计的自动化工具，能够批量导入SRT字幕文件到序列的字幕轨道，并自动整理素材箱。

### 核心功能

- **智能文件扫描** - 自动扫描指定目录中的SRT文件
- **智能序列匹配** - 基于文件名数字自动匹配对应序列
- **坐标配置器** - 图形化界面配置操作坐标
- **自动化导入流程** - 模拟用户操作自动导入字幕
- **素材箱整理** - 自动创建素材箱并整理SRT文件

## 安装和环境要求

### 系统要求
- Windows 10/11
- Python 3.7 或更高版本
- Adobe Premiere Pro (任何支持的版本)

### 依赖库安装
```bash
pip install -r requirements.txt
```

或手动安装：
```bash
pip install pymiere pyautogui keyboard Pillow
```

## 使用方法

### 1. 准备工作
1. 启动 Adobe Premiere Pro
2. 打开包含需要添加字幕的序列的项目
3. 准备好SRT字幕文件，确保文件名包含与序列名称匹配的数字

### 2. 启动程序

#### 方法一：双击启动（推荐）
```
双击 START_SRT_IMPORTER.bat
```

#### 方法二：命令行启动
```bash
python srt_subtitle_importer.py
```

### 3. 操作步骤

#### 步骤1: 文件扫描
1. 点击"浏览"按钮选择包含SRT文件的目录
2. 点击"扫描SRT文件"按钮
3. 查看扫描到的SRT文件列表

#### 步骤2: 文件匹配
1. 点击"智能匹配序列"按钮
2. 查看匹配结果，确认SRT文件与序列的对应关系

#### 步骤3: 坐标配置
1. 按顺序配置四个关键坐标：
   - **坐标1**: 文件导入按钮位置
   - **坐标2**: 字幕样式下拉菜单位置
   - **坐标3**: 字幕样式选择位置
   - **坐标4**: 确定按钮位置
2. 点击"获取坐标"后，将鼠标移动到目标位置，按F1键确定
3. 点击"测试所有坐标"验证配置是否正确

#### 步骤4: 执行导入
1. 确认导入选项（是否自动创建素材箱）
2. 点击"开始自动导入"按钮
3. 程序将自动按数字顺序导入所有匹配的SRT文件

## 文件匹配规则

程序使用智能算法匹配SRT文件和序列：

### 数字匹配示例
```
序列: "视频01" ↔ SRT: "01.srt"           # 匹配数字: 01
序列: "scene_05" ↔ SRT: "字幕05.srt"     # 匹配数字: 05
序列: "clip-10" ↔ SRT: "subtitle_10.srt" # 匹配数字: 10
```

### 支持的文件格式
- **字幕文件**: .srt

## 自动化流程详解

### 导入流程
1. **文件导入**: 点击PR中的文件导入按钮
2. **目录导航**: 第一个文件时自动导航到SRT目录
3. **文件选择**: 输入SRT文件名并确认
4. **样式设置**: 选择字幕样式
5. **确认导入**: 点击确定按钮完成导入

### 坐标配置说明
- **坐标1 (文件导入按钮)**: PR界面中的"导入"或"Import"按钮
- **坐标2 (字幕样式下拉菜单)**: 字幕导入对话框中的样式下拉菜单
- **坐标3 (字幕样式选择)**: 下拉菜单中的具体样式选项
- **坐标4 (确定按钮)**: 导入对话框中的"确定"或"OK"按钮

## 故障排除

### 常见问题

#### 1. 程序无法启动
**症状**: 双击bat文件没有反应或报错
**解决方案**:
```bash
# 检查Python是否正确安装
python --version

# 检查依赖库
pip list | findstr pymiere
pip list | findstr pyautogui

# 手动安装依赖
pip install -r requirements.txt
```

#### 2. 连接Premiere Pro失败
**症状**: 显示"连接失败"
**解决方案**:
- 确保 Premiere Pro 已启动并打开项目
- 确保pymiere扩展已安装并启用
- 参考主程序README中的pymiere安装说明

#### 3. 坐标配置失败
**症状**: 按F1键没有反应或坐标不准确
**解决方案**:
- 确保程序有管理员权限
- 检查是否有其他程序占用F1键
- 尝试重新配置坐标

#### 4. 自动化操作失败
**症状**: 导入过程中出现错误或卡住
**解决方案**:
- 检查坐标配置是否准确
- 确保PR界面没有被其他窗口遮挡
- 调整操作间隔时间（修改代码中的time.sleep值）

#### 5. 文件匹配不准确
**症状**: SRT文件与序列匹配错误
**解决方案**:
- 检查文件名和序列名是否包含相同数字
- 确保数字格式一致（如01 vs 1）
- 手动重命名文件以符合匹配规则

### 权限问题
如果遇到权限错误：
- 以管理员身份运行程序
- 右键点击START_SRT_IMPORTER.bat，选择"以管理员身份运行"

## 使用技巧

### 最佳实践
1. **文件命名**: 确保SRT文件名包含与序列名相同的数字编号
2. **坐标配置**: 在配置坐标前，先打开PR并准备好导入界面
3. **测试运行**: 在批量导入前，先用少量文件测试流程
4. **备份项目**: 在使用自动化工具前建议备份项目文件

### 工作流建议
1. 准备好所有SRT文件，确保命名规范
2. 在PR中创建好对应的序列
3. 启动字幕导入工具
4. 按步骤完成扫描、匹配、坐标配置
5. 执行自动导入
6. 检查导入结果，进行必要的调整

## 注意事项

### 安全提醒
- 自动化操作期间请勿移动鼠标或使用键盘
- 确保PR界面完全可见，不被其他窗口遮挡
- 建议在导入前关闭不必要的程序

### 性能优化
- 大批量文件导入时建议分批处理
- 可以调整代码中的延时参数以适应不同性能的电脑
- 确保有足够的磁盘空间和内存
